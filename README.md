# TCG Card Investment Database

Windows desktop release for local TCG card investment management.

## Latest Download

- Recommended for most users:
  [TCG卡牌投资管理数据库-1.0.6-x64-setup.exe](./TCG卡牌投资管理数据库-1.0.6-x64-setup.exe)
- No-install build:
  [TCG卡牌投资管理数据库-1.0.6-x64-portable.exe](./TCG卡牌投资管理数据库-1.0.6-x64-portable.exe)

## What This App Does

- Create separate TCG libraries
- Add card master records with image, name, card number, series, rarity, rating, tags, and notes
- Record purchase history for each card
- Record sales against purchase records
- Record investment plans and target positions
- Automatically calculate inventory quantity, average cost, realized profit, and quantity gap
- Filter cards by keyword, group, tag, owned-only, and planned-only
- Support local image upload and direct clipboard paste

## How To Use

1. Download `setup.exe` if you want a standard installation.
2. Download `portable.exe` if you want a standalone executable.
3. Launch the app and create your first card library.
4. Add card entries, then add purchase, sale, and investment records.

## Notes

- Supported system: Windows x64
- This build is currently unsigned, so Windows may show an "Unknown Publisher" or SmartScreen warning.
- User data is stored locally on the current Windows account.
