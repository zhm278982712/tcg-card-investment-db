## Features / 主要功能

- Create separate TCG libraries  
  创建多个独立卡牌库
- Add card master records with image, card name, card number, series, rarity, rating, tags, and notes  
  录入卡牌主档，包括图片、卡名、编号、系列、稀有度、评级、标签和备注
- Record purchase history, sale history, and investment plans for each card  
  为每张卡记录购买记录、出售记录和投资计划
- Automatically calculate inventory quantity, average cost, realized profit, and quantity gap  
  自动计算库存数量、平均成本、已实现利润和计划缺口
- Filter cards by keyword, group, tag, owned-only, and planned-only  
  支持按关键词、分组、标签、仅看有库存、仅看有缺口筛选
- Support local image upload and direct clipboard paste  
  支持本地图片上传和剪贴板直接粘贴

## Quick Start / 快速使用

1. Download the `setup.exe` build if you want a normal installation.  
   如果你想正常安装，下载 `setup.exe`。
2. Download the `portable.exe` build if you want a standalone executable.  
   如果你想免安装直接运行，下载 `portable.exe`。
3. Launch the app and create your first card library.  
   启动软件后先创建第一个卡牌库。
4. Add card entries, then add purchase, sale, and investment records.  
   先录入卡牌条目，再补充购买、出售和投资记录。

## Notes / 注意事项

- Supported system: Windows x64  
  支持系统：Windows x64
- This build is currently unsigned, so Windows may show an "Unknown Publisher" or SmartScreen warning.  
  当前版本未签名，Windows 可能提示“未知发布者”或 SmartScreen 警告。
- User data is stored locally under the current Windows account.  
  用户数据保存在当前 Windows 账户的本地目录中。
