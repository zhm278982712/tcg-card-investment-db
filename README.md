# TCG Card Investment Database

Windows release package for end users.

## Files

- `TCG卡牌投资管理数据库-1.0.6-x64-setup.exe`
  Installer build for most users.
- `TCG卡牌投资管理数据库-1.0.6-x64-portable.exe`
  Portable build that runs without installation.
- `USER_GUIDE.txt`
  English quick guide.
- `使用说明.txt`
  Chinese quick guide.
- `CHANGELOG.txt`
  Release notes.
- `CHECKSUMS.txt`
  SHA256 checksums.

## Recommended usage

1. Use the `setup.exe` build if you want a standard installation.
2. Use the `portable.exe` build if you want a standalone executable.

## Notes

- This release targets Windows x64.
- This build is currently unsigned, so Windows may show an "Unknown Publisher" warning.
- The app stores user data on the local machine under the current Windows user profile.
